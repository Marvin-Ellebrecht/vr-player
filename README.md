# VR Player

Play 180° or 360° immersive videos on your VR headset using WebXR APIs. Supports most common VR HMDs.

Supports mono or stereo video playback with top-bottom or left-right layouts.

## Features

This fork includes 
- an auto-installer for Windows and Linux. After installation, the folder is portable.
- a gallery with auto-play previews
- a working monitor previewer
